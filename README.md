# syndical-lab-

AI-powered caption generator for social media content.

## What it does

Generates captions for images/videos using an LLM API. Part of the SYNDICORE ecosystem.

## Usage

```bash
pip install -r requirements.txt
python caption_generator.py --input image.jpg
```

## Setup

```bash
cp .env.example .env
# Add your API keys
```
